| 项 | 值 |
|---|---|

| 标志 | 「cc-mods」为临时字标（JetBrains Mono 700），没有母版 |
| 声音 | 只有配乐，无旁白、无音效。配乐是《栖谷来信》（Letter from an old friend，制造木屋/陈越龙，2026）：原曲 130 秒，用 `tools/cut_music.sh` 剪成 77 秒，原曲 0–37.49 秒接 88.87–128.44 秒，原曲的结尾和弦落在收尾字标上。成片 −14 LUFS，真峰值不高于 −1 dBTP |

未使用风格包，没有题材禁用清单要对照。

## 素材

终端画面都是真实会话的录屏数据，按字符格重排成 DOM；实录帧按拍点排列，不按原速播放。含账号用量提示的行一律清空。

| 编号 | 用在 | 内容 | 录法 |
|---|---|---|---|
| R0 | 1、2.1、4–7 段 | 第 1 版的实录数据：2026-10-04，Haiku，截 iPad 模拟器 + 4 条 sleep；shot-view 面板里的图片区域为合成 | 已有 |
| R1 | 2.1 | 没装 mod 的会话：与 R0 同样的提示词，Claude 在跑 `sleep 70`，输入框上方只有转圈那一行 | 用 `--settings` 关掉三个 cc-mods |
| R2 | 2.3 | 官方文档的计数器示例：发出「list the files here and read the README and package.json」，转圈那一行从 `tool calls: 0…` 数到 `3…` | `--plugin-dir` 加载示例，cc-mods 关掉 |
| R3 | 2.4 | 官方示例 blast-radius 拦下 `rm -rf build`：面板列出会删掉的 9 个文件，焦点在 Cancel，按回车取消，Claude 回复「命令被取消了」 | 临时目录里放一个 `build/` |
| R4 | 2.5 | Claude 改了两个文件后，输入 `/diff` 打开 Claude Code 自带的 diff 面板 | 临时 git 仓库 |

## 实现中相对确认版的改动

| 位置 | 改动 | 原因 |
|---|---|---|
| 时间 | 各事件从分镜的 60 BPM 网格挪到《栖谷来信》实测的起音上，最多挪 0.9 秒；收尾落在原曲的结尾和弦上 | 分镜按 60 BPM 写，这首曲子约 68 BPM 且速度有起伏 |
| 2.2 字幕 | 「…会先调用你写的函数」改为「…画界面前，先调用它」 | 原句 48px 一行放不下 |
| 2.3 | 多一帧 `tool calls: 0…` 作全景；提示词多要求读一个 package.json | 全景先交代起点；多读一个文件，保证能数到 3 |
| 2.4、2.5 | 推近面板时左边的对话淡下去 | 推近后面板左侧会露出被裁断的对话 |

## 版本记录

- 第 1 版（36 秒，commit 4b44266）：开场、mod 是什么（5 秒，文件树与代码摘录卡片）、三个 mod、收尾；合成音床 pluck 与 53 个合成音效。
- 第 2 版（77 秒）：「mod 是什么」扩成 45 秒，改用真实录屏讲（装没装的对比、官方示例的代码和效果、blast-radius 拦截、自带的 /diff、validate），只保留一张对比卡；配乐换成《栖谷来信》的剪辑版，去掉合成音效；ctx-slim 字幕改为「按你配的目录规则」，对应 ctx-slim 0.3.0 改成可配置。
