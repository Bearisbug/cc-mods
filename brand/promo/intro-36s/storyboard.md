# cc-mods 介绍短片 · 分镜

| 项 | 值 |
|---|---|
| 用途 | GitHub README 与演示：介绍 Claude Code mods 和 cc-mods 的三个 mod |
| 总时长 | 36.0 秒（1080 帧） |
| 画幅 | 16:9，1920×1080 |
| 帧率 | 30 fps |
| 风格包 | 无合适的包，按 `CRAFT-002` 自定义：终端实录风 |
| 渲染层 | HTML（HyperFrames 0.8.96 + GSAP 3.15.0） |
| BPM | 120（一拍 15 帧，半拍 7.5 帧） |
| 配色 | 舞台 `#0B0B0D`；终端窗 `#161618`；窗口描边 `#2A2A2E`；主文字 `#ECEAE6`；次文字 `#8C8C91`；Claude 橙 `#D77757`（片名强调）；截图蓝 `#4782C8`；进度紫 `#AF87FF`；精简绿 `#4EBA65`（后三色取自 mod 在 dark 主题下的实际颜色） |
| 字体 | 中文标题与字幕 Noto Sans SC 700/900；终端、代码与英文 JetBrains Mono 400/700 |
| 缓动 | 入场 `power3.out` 0.4 秒；镜头推拉 `power2.inOut` 0.6 秒；弹出 `back.out(1.6)` 0.25 秒；退场 `power2.in` 0.25 秒 |
| 标志 | 「cc-mods」为临时字标（JetBrains Mono 700），没有母版 |
| 素材 | 终端画面取自 2026-10-04 一次真实会话的录屏数据（Haiku，Temp 目录，截 iPad 模拟器 + 4 条 sleep），按字符格重排成 DOM；shot-view 面板里的图片区域为合成（录屏用的终端模拟器不支持 kitty 图片协议）；含账号用量提示的行已清空 |
| 声音 | 合成配乐与音效，无旁白。音床 `pluck`，和弦 Am–F–C–G 每 4 拍一换，无鼓，增益 0.45 |

未使用风格包，没有题材禁用清单要对照。

## 实现中相对确认版的改动

| 位置 | 改动 | 原因 |
|---|---|---|
| 3、4 段键帽 | 从画面右下改到底部居中 | 右下会盖住截图面板底部的按键提示；键帽与字幕不同时出现，放字幕位不冲突 |
| 4 段 23.2 秒 | 增加推近到「任务完成」那一行 | 全景里这一行太小，读不出来 |
| 5 段说明块 | 放进一张不透明的浮层卡片 | 直接叠在终端输入框那几行上显得杂乱 |
